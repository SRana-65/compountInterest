# Compound Interest Calculator

## Project Description
This project calculates Compound Interest using JavaScript.

## Formula
A = P × (1 + r/n)^(n×t)

Compound Interest = A - P

## Technologies Used
- HTML
- JavaScript

## Project Files
- index.html
- script.js
- README.md

## Expected Output
Compound Interest after 3 years is : 50000

## How to Run
1. Open the project folder.
2. Open index.html in your browser.
3. Check the browser console to see the result.
